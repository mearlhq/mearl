# 沉浸式翻译

在要翻译的网页上打开 Mearl Popup，进入工具箱「沉浸式翻译」选择目标语言和翻译引擎后，可点「翻译本页」仅处理当前文档，或点「开启本站翻译」在刷新和再次访问时自动恢复；自动模式和 Codex 引擎还可选择模型和思考级别。引擎、模型、思考级别、语言、段落上限和悬浮开关和拖动位置为全局偏好，选择后自动保存；本站开启/关闭按当前主机名和端口保存，HTTP/HTTPS 共用，子域名独立。本页翻译的停止与重译不修改本站规则，也不影响其他页面。设置在 Popup 展示，自动使用当前网页；可在「更多设置」启用页面悬浮开关。这些设置和操作仅供 Popup 工具页使用，不作为 Agent 的公开命令。Agent 为回答问题而读取或分析网页时，应使用 Mearl 的页面读取能力获取原文，无需先启动本工具。

以下名称说明工具页内部控制契约，方便维护，不代表 CLI 或 Agent 接口。

- Popup 通过 `bootstrap` 在一个命令内并行读取全局偏好和当前页面进度，页面列表、激活规则与目标标签信息并行查询。数据就绪前显示静态占位，不先展示默认引擎；模型目录异步补齐，保留已选模型，不短暂切到自定义输入框。页面事件触发实际进度刷新，历史 running 事件不直接覆盖完成状态。
- `settings` 的 `floating` 为布尔值，默认关闭；`floatingPosition` 用归一化的 `{x,y}` 保存拖动位置。开启后通过全局 HTTP(S) 激活范围在已授权网页插入悬浮开关，本站自动翻译仍由各站点独立范围判断，插入开关本身不启动翻译。默认右侧中下方，可拖动且不触发翻译，松手后保存位置，刷新和再次访问时恢复；位置按视口尺寸适配并限制在屏内。关闭时移除开关，保留正在翻译的页面。悬浮开关首次点击启动当前页翻译，之后切换原文与双语，复用已有译文；切回原文只切换显示，后台翻译继续，停止任务使用 Popup 的停止操作。等待切换时显示小型 loading，遵守减少动态效果设置。页面 UI 挂在 documentElement 下，使用 Shadow DOM 隔离样式，停止后保留空闲入口，导航或解绑时清理。

- `start-page` 仅启动当前文档，`stop-page` 取消当前翻译并恢复原文，两者均保留已有本站激活规则；`start` 开启本站自动翻译。仅翻译本页时，重新翻译或应用偏好使用 `start-page`，不会开启本站规则。新文档导航与刷新后，只有已开启本站规则的页面会自动恢复。

- `start` 的 `engine` 可选 `auto/codex/browser`，默认 `codex`。浏览器内置引擎在目标文档的隔离环境中使用 Chrome Translator API，不启动 Codex，不经过模型服务，也不会在不可用时自动回退。通过 Language Detector API 逐段识别原文语言；检测器不可用或置信度不足时可使用段落声明的 `lang`；存在声明语言时检测结果需达到 0.9 置信度，避免短品牌词触发错误语种和额外语言包。原文和目标语言相同时保留原文。语言包由浏览器按需下载，浏览器要求激活时工具页提示在目标网页点击或按键，完成后自动继续，并展示下载进度。原生翻译单次页面请求最多等待 300 秒，允许语言包准备和网页交互，停止或取消仍会立即中断。页面需支持该 API 且满足安全上下文及 Permissions Policy 要求；不支持的浏览器或网页显示错误，可手动选择 Codex。浏览器翻译逐段预览，确认后缓存；原生翻译或语言检测实例发生可恢复的内部错误时销毁并重建一次，仍失败的片段单独记录，不阻塞后续段落；成功结果正常确认和缓存，失败内容保留原文，工具页分别统计待译和失败段落并提供重试。行内代码词不交给本地模型，保持原样。重译、导航、停止或取消会中断等待和执行并回收文档拥有的资源。
- 自动模式（`engine: "auto"`）适合边读边翻译：浏览器内置队列只处理当前可见且没有 Codex 结果的段落，Codex 独立队列先处理当前屏，再预翻译下一屏；两条队列互不等待，每次取批次都按最新视口重新排序，不提前排入整页。浏览器队列在执行前同时查询两种缓存，优先回写当前模型的 Codex 缓存；缓存恢复事件也按 Codex、浏览器顺序处理。已确认的 Codex 译文始终高于浏览器结果，迟到的浏览器结果不会覆盖它；浏览器译文可在 Codex 运行时先显示，Codex 最终校验通过后替换。自动模式的预译正文与正式译文使用相同的主题蓝，仅以虚线下划线区分，整段 Codex 结果确认后去掉虚线；缓存直接命中 Codex 结果时直接显示完成样式，精译失败时保留预译虚线。浏览器内置单引擎模式沿用正常译文样式。Codex 临时流式结果失败时保留已确认的浏览器译文，两种结果分别写入原有独立缓存，不把浏览器结果当作 Codex 缓存。滚动时新进入视口的内容可立即进入浏览器队列；已经发出的 Codex 批次允许完成，随后优先当前视口。失去阅读价值的浏览器等待会取消，开始前已移出视口或已获 Codex 结果的片段释放而不记为失败。后台标签页暂停新增计算，已发出的 Codex 请求可完成并缓存，回到前台时继续。工具页分别展示已有译文数与 Codex 译文数；一个引擎失败时保留另一引擎并提示具体原因，重试不删除已有译文。停止、导航和重译隔离两条队列的旧代次。自动模式会使用已选 Codex 模型服务，浏览器内置模型负责先行显示；选择浏览器内置模式可仅使用设备上的翻译。
- `start` 支持目标语言 `zh-CN/en/ja/ko`，`maxParagraphs` 为 1–500，默认 200；可选 `model` 使用本机 Codex 支持的模型标识。自动模式和 Codex 引擎下 Popup 从宿主异步加载可选模型列表，同时提供“跟随本机配置”和自定义模型名，加载模型列表不阻塞开始翻译。不指定时跟随本机 Codex 默认模型。`reasoningEffort` 默认 `low`，可选 `default/none/minimal/low/medium/high/xhigh/max`；`default` 跟随模型默认值。Popup 依据模型目录展示该模型支持的级别，切换模型时修正不支持的选择。较低级别通常更快，但不会加速缓存恢复。运行中的页面固定本次引擎、模型、思考级别与语言；修改全局偏好对新页面生效，当前页点“应用并重译”应用。开始后立即返回实例与状态，模型任务继续在后台执行。
- 页面按段落处理，覆盖文章、侧栏阅读内容、列表卡片、正文中的独立块级链接标题及非语义正文容器；列表中的块级标题链接单独翻译，保留链接交互和列表缩进。仅导航语义（`nav`、`role="navigation"`）按导航过滤，`aside` 本身不视为导航。提取原文时排除隐藏节点、tooltip、屏幕阅读器专用文字及装饰性 SVG；可见性判断在每次同步处理内缓存，段落切到译文模式时仍保留原文身份。受行数限制的标题在显示译文时解除截断，切回原文或停止时恢复。翻译任务按阅读位置推进：先完成当前视口，再预取下一个视口；远处内容在滚动接近后入队，已译段落保留，`deferred` 表示尚未入队的远处段落。Codex 引擎在同一页面与翻译代次复用临时会话，后续批次免去重复的进程和首轮初始化；重译、导航、停止、错误或取消时隔离或释放旧会话，空闲 5 分钟释放，每 32 轮重新建立临时会话限制历史增长。首批最多 4 个文本片段、后续最多 8 个；每批结束后按最新视口取下一批，不预先占住多批模型任务。缓存先回写，缺失内容交给模型。一批合并请求多段，按输入顺序返回结构化 JSON；流式识别完整的单段对象，校验 ID、文本及代码词后立即临时显示，不等待整批结束。长段落的全部片段齐全后显示；最终完整结果通过宿主 schema 和业务校验后确认并缓存，流中断或校验失败撤回本批临时译文，重译或导航不接收旧代次结果。流式信息缺失、格式不符或序号不连续时回退到最终结果；后台一次连续处理有界队列，每次最多 16 个片段批量恢复缓存，命中不等待模型请求。模型运行时，新进入阅读区域的缓存由独立事件处理；已在本页显示过的译文另存于有界内存缓存，虚拟列表重建段落时可同步恢复。滚动合并采用固定 60 ms 截止时间，不因连续滚动延后；仅视口变化时复用已识别段落，正文或布局变化时重做检测。保留原网页节点，译文在对应段落下方自然换行，沿用原文字号、字重和列表对齐，以主题蓝区分原文。已入队或正在翻译的段落在原文末尾显示小型加载标记，快速缓存命中不闪烁；显示原文、翻译完成、失败或停止时清理标记，并尊重减少动态效果的系统偏好。横向 flex 和多列 grid 容器内的译文独立占行，字号沿用实际文字标签；切换原文或停止时恢复插件调整的换行样式。模型输出始终按文本处理，不解析模型生成的 HTML。正文行内链接保存可见文字范围，Codex 通过边界标记保留整段翻译语境，浏览器内置引擎分别翻译链接文字和周围正文；流式预览和正式结果校验标记完整性，译文依据原网页节点重建链接地址、target 和 rel，沿用页面链接样式，不额外指定颜色。链接范围参与两种引擎的缓存身份，避免复用缺少链接的纯文本结果；长链接可随段落分块，显示模式切换时保留译文链接，源链接地址变化时同步更新。行内代码词原样保留，并仅依据原网页的代码节点恢复格式。原链接和表单保持原样。指向当前文章章节标题的目录提供双语标签，并保留链接点击和图标布局；站点菜单、分类筛选等紧凑链接控件仍跳过。跳过其余导航、表单控件、代码块、隐藏区域和 `translate="no"` 内容；超过 12000 字符的单段，或包含超过 64 个行内代码节点、超过 1600 字符的行内代码的段落跳过。数量限制和跳过数在工具页展示。已译、待译、失败和缓存复用统一按段落计数；已识别数只代表当前可识别内容，不代表网页后续异步内容已全部加载或整页已翻译；进度仅统计已入队段落。
- `state` 读取实际进度；`display` 的 `mode` 为 `original/bilingual/translated`，分别显示原文、双语或译文，切换显示不会停止后台翻译或重新调用模型。译文模式仅隐藏已有译文段落的原文，待译或失败段落继续显示原文；切回双语、原文或停止时恢复原节点。`retry` 只重新入队失败片段，保留已译内容和缓存；已失败段落不会随滚动自动重复调用。`stop` 关闭本站自动翻译、恢复本站所有页面原文并取消其后台任务，其他站点不受影响；已开启悬浮开关时保留空闲页面入口。
- 工具页关闭后继续翻译；重新打开可读取同一实例进度。动态新增或变更正文会重新识别，结果回写前检查原文与页面代次。已开启站点在刷新、新文档导航和浏览器重启后由宿主持久激活规则自动恢复，初始化时读取最新全局偏好；同文档 SPA 导航会继续处理新正文。
- 两种基础引擎的翻译缓存独立，自动模式复用它们并优先选择 Codex；Codex 缓存按原文、目标语言与模型选择隔离，浏览器缓存按原文、目标语言与声明的源语言隔离（切换 Codex 思考级别可复用已有译文，浏览器缓存不受 Codex 模型选择影响），最多保存 7 天。可用缓存直接回写；改变原文或目标语言不会套用旧译文。

依赖扩展连接、目标域名授权与「允许用户脚本」。依宿主提示完成授权。Codex 引擎使用显式只读模型任务，复用当前 Codex 配置与登录态；没有配置或登录时按模型错误处理。本机 Codex 执行入口不代表离线推理，正文由配置的模型服务处理。浏览器内置引擎在设备上运行，语言包准备完成后无需模型服务连接。

遇到 `PLUGIN_NOT_REGISTERED` 时，读取本次 Skill 的实际目录并运行 `npx @mearl/setup plugin "$SKILL_DIR"` 注册一次后重试。其余业务或模型失败显示具体错误，不切换到其他翻译服务。
