### Preset 安装与授权

- 在扩展设置中直接打开 Preset 安装对话框。已有站点访问权限时，可在启用前查看用途说明或能力数量，切换 Preset 时会同步更新预览和所需权限。
- 站点授权弹窗支持允许 Agent 访问所有站点，也可仅允许当前请求的站点。Agent 接入对话框更新了常用能力说明。
- 安装器在安装和更新后以文本显示结果及待处理事项。需要读取 JSON 的脚本可调用 `npx @mearl/setup preset status`，Preset 未就绪时退出码仍为 `3`。
- 「添加 App Profile」移除了内置的微信选项。仍可从受支持的来源手动安装 App Profile。

### 浏览器会话与 Provider

- 结束会话时默认关闭会话新建的标签页，复用的用户页面会保留。用 `keepTabIds` 保留指定结果页，或用 `closeCreatedTabs: false` 保留全部标签页。Provider 未提供 `tab_close` 时会保留页面并释放会话。
- 在 macOS 上，声明了对应浏览器 Bundle ID 的 Provider 可避免同一浏览器同时通过扩展出现在本机发现结果中。扩展内的 Agent 服务由用户设置控制。
