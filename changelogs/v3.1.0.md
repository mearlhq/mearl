### 浏览器与控制会话

- 用 `browser_list` 查看浏览器，通过 `browser_manage` 启动、接入、断开、释放控制或关闭实例。用 `session_list` 和 `session_manage` 管理任务会话，显式创建和结束分别用 `new` 和 `end`。使用旧命令的脚本需要迁移，随 CLI 分发的指南已更新。
- Chrome 和 Electron 可通过 CDP Provider 接入。没有扩展连接时，Chrome 仍可通过 CDP 自动发现。显式接入使用 `browser_manage` 的 `attach` 操作。
- 独立的 [Firefox Provider](https://github.com/mearlhq/provider-firefox) 通过 WebDriver BiDi 接入已启用本机调试端口的 Firefox。支持页面快照、点击、输入和截图。断开连接后保留 Firefox 和标签页。

### 调试与端模拟

- 支持录制浏览器页面并导出视频，工具箱新增网页终端。
- 设备预览支持 SPM 高亮和源码定位，改进了端模拟的操作入口。
