# Mearl 3.0.2

[简体中文](v3.0.2.md) | English

### Highlights

Preset installation can be retried from a saved local snapshot. A dedicated command removes an installed Preset.

### Features

- `preset uninstall` removes the local Preset, matching selections in connected extensions, and managed registrations in the current Preset's plugin catalog. Independent capabilities, Skill files, Providers, and browser permissions are preserved.

### Changes

- Run `preset apply` without a source to retry from the saved local snapshot. This replaces `preset repair`. Pass a URL or local file to install or switch Presets.

### Fixes

- When a Skill comes from the same repository and its receipt omits the branch, setup installs and verifies the branch declared by the Preset.
- The installation page reports browser readiness based on settings the browser must apply, preventing false errors caused by local installer settings.

### Upgrading and compatibility

- Run `npx @mearl/setup@3.0.2` to install, or `npx @mearl/setup@3.0.2 update` to update local components. Browser-side removal requires matching versions of the Native Host and extension.
