### Preset installation and account permissions

- If you install a Preset through the CLI before installing the extension, the first sync opens the permission window when site access is still missing and lists the sites that need it.
- **Retry** in the account picker requests the Preset scopes that cover the account site, including matching parent-domain wildcards. If you have already granted access to the subdomain, you can add the parent-domain permission. The account list refreshes after approval.
- **Install** and **Update** in extension settings open the same dialog. When updating, the dialog preselects the current Preset if it is in the catalog and reuses loaded capability previews.
- Preset removal has moved to the CLI. Run `npx @mearl/setup preset uninstall` to remove the current configuration.
