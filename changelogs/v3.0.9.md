### 安装引导

- 首次安装时优先探测构建配置指定的欢迎页，网络可达时打开该页面，失败或超时后回退到公网欢迎页。探测不再依赖目标网站的 Manifest 主机权限。
- 本地构建支持 `.env.local` 配置欢迎页；发布构建读取同名 GitHub 仓库变量。

### 更新与发布

- 扩展、CLI 检查和稳定版 setup 从 GitHub Pages 读取更新配置；发布成功后自动刷新网站配置，不受商店提审结果影响。
- beta setup 直接下载与自身版本一致的扩展 ZIP；显式指定更新配置源的用法保持有效。
- Release 仅附带扩展 ZIP 和许可证，不再生成 `config.json`、`toolbox.json` 附件。依赖旧 Release 配置地址的客户端需升级。
- 移除扩展对 `github.com` 和 `release-assets.githubusercontent.com` 的常驻主机权限。
