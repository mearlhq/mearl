### 版本重点

扩展安装后的欢迎页可检测并打开配置的自定义官网，安装器也改善了不同 Node.js 版本下的 Skills 兼容性。

### 新增

- 欢迎页支持探测经代理访问的 HTTPS 端点。浏览器和已连接的本机宿主均无 Preset 时，引导页会自动发起首次安装。已有 Preset 可手动更新或切换，所需权限在扩展安装页确认。

### 变更

- 扩展使用独立的页面注入入口，并减少准备和校验 Preset 资源时的重复工作。
- 快速开始优先介绍 Agent 配置，并提供可复制的配置提示词。

### 升级与兼容性

- Setup 按当前 Node.js 版本选择兼容的公共 Skills CLI。
- 运行 `npx @mearl/setup@3.0.1` 安装，或运行 `npx @mearl/setup@3.0.1 update` 更新本机组件。
