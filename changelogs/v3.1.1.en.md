### Page uploads and interactions

- In the Chrome extension, `page_upload.files` uploads local files or browser artifacts to file inputs on HTTP(S) pages without **Allow access to file URLs**. Chunked uploads support up to 256 MiB total per action. Use `filePaths` for large files or sites that require native file selection events. The extension requires the setting for `filePaths`. Direct CDP uploads do not require the extension setting.
- Fix visible controls being reported as clipped by the `body` after scrolling.
- When page monitoring times out during startup, the message prompts callers to inspect the current page state before retrying.
