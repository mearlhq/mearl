### Browser Manager

- When adding a browser, Provider field labels, descriptions, placeholders, and options follow the interface language. Numeric inputs can also display placeholders.
- Providers can choose which identifier appears in the collapsed browser row and translate labels in the details view. To see the updated text for EgoLite, Brow, Bumble, or AgentBay, update both the extension and the corresponding Provider.

### App simulation

- The page context menu shows “Enable app simulation” or “Disable app simulation” based on the current tab.
- When enabling App simulation with a device shell for the first time, the shell can load on the first page reload.
