### Browser control

- Ordinary new tabs without a control session can navigate concurrently over local CDP. Reading and taking screenshots of other tabs can continue while a slow page loads. New tabs report their navigation state. A readable document returns `ready`. A navigation acknowledgment timeout returns `pending`, and callers can use the same `tabId` to check its progress.
- Fix drag delays that accumulated across mouse and touch move acknowledgments. Slow acknowledgments cause overdue intermediate moves to be skipped while the drag still attempts to reach the endpoint and release the input.
- Closing local managed Chrome cancels actions that have not been dispatched and sends the close receipt after confirming Chrome has exited. The local host enforces the overall script deadline before dispatching queued actions. If the host cannot return a new control session to the caller before the deadline, it releases that session's claims on any tabs.

### Extension and website

- The toolbox can open a cached tool first and prompt for a refresh when an update is available. The browser list reduces flickering during brief loads.
- Update the installation and usage guides. The offline extension ZIP download link comes from the website's update configuration.
