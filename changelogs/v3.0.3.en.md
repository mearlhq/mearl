### Highlights

Users now start Preset installation from the website guide and grant any required permissions in the extension.

### Changes

- The guide checks the selected Preset's status when it opens. Clicking Enable opens the extension installation page.
- The welcome page probes the configured HTTPS custom website directly. Site operators supply the installation catalog JSON through `MEARL_INSTALLATION_CONFIG`.
- Updated the Chrome extension's English and Chinese product descriptions.

### Fixes

- The embedded installation button omits the Preset name already shown by the guide.

### Upgrading and compatibility

- Run `npx @mearl/setup@3.0.3` to install, or `npx @mearl/setup@3.0.3 update` to update local components. Use matching versions of the website guide and extension.
