### 新增

- 为独立 Ego Provider 提供原生页面宿主，支持页面操作、设备外壳、根 WebView 和已安装 App 的协议与授权服务。
- Provider 可声明宿主浏览器的 macOS Bundle ID，让该浏览器配置的扩展 Agent 接入默认关闭。用户可手动覆盖，偏好不跨浏览器同步；离线或移除 Provider 不会自动重新开启。
- 增加 `pnpm dev:link`，支持构建并链接本地 CLI 包供源码开发使用。

### 修复与兼容性

- 协调握手完成前阻止 Agent 接入；关闭后，文件上传、批量页面动作和登录态复制同样受开关约束。管理连接仍可用于安装和设置。
- 宿主请求随控制权撤销而中止，避免交还后继续处理过期授权；策略通过变更事件更新，不新增定时轮询。
- Ego 使用独立 `provider-ego`，移除 `mearl-ego` Skill，并更新官网中英文指南。启用自动协调需更新扩展和 Native Host，再重新注册 Provider。
