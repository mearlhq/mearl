### SPM inspection

- With SPM highlighting enabled in the tracking panel, hold Command (⌘) on macOS to pick temporarily. Release the key to exit.
- In continuous mode, the details for the selected tracking point stay visible until you pick another point. For elements without readable text, the details can show the accessible label, title, alternative text, or placeholder.

### Skill installation

- Adding `--skill <name>` to the `@mearl/setup` command `plugin install` uses the active Skills manager’s defaults without prompting. Use `--agent <id>` to select an agent, or omit `--skill` to choose interactively.
- Installing or updating the global Mearl Skill also uses the active Skills manager’s defaults.
