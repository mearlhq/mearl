# Mearl 3.0.1

[简体中文](v3.0.1.md) | English

### Highlights

The extension's welcome page can detect and open a configured custom website. Setup improves Skills compatibility across Node.js versions.

### Features

- The welcome page can probe HTTPS endpoints reached through a proxy. The guide starts first-time installation when neither the browser nor the connected local host has a Preset. Existing Presets can be updated or switched manually. Confirm required permissions in the extension installation page.

### Changes

- The extension uses a dedicated entry point for page injection and avoids duplicate work when preparing and validating Preset resources.
- Quick Start puts Agent configuration first and provides a copyable setup prompt.

### Upgrading and compatibility

- Setup selects a public Skills CLI compatible with the running Node.js version.
- Run `npx @mearl/setup@3.0.1` to install, or `npx @mearl/setup@3.0.1 update` to update local components.
