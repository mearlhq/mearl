### Device emulation and site permissions

- Custom timezones can be applied to the current site again. Settings offers a permission prompt when site access is needed and keeps the current selection if applying the timezone fails.
- App Profile user agents match the selected device preset. Quick Settings provides an entry for adding app emulation. When continuing emulation on another site, users can grant access to that site or turn off emulation and continue browsing.
- Browser Manager identifies the current browser by ID, so instances with the same name are distinguishable.

### CLI and external browser control

- `mearl browser_list` reports registered external Providers in `installedProviders`, including Providers with no browser instances yet.
- `mearl guide skills` shows the purpose and installation sources of specialized Skills from the active Preset.
- For pages controlled by external tools, request and log capture follows the active control grant. Pausing or ending control stops pending capture queries. Capture starts again when control resumes.
