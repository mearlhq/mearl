### SPM tracking inspection

- With Highlight SPM enabled in the tracking panel, select highlighted elements to see the full SPM, tracking type, configuration, and DOM details.
- Click the picker once for a single selection or double-click for continuous selection. Repeated clicks cycle through overlapping highlights. The selected details stay open until the next selection.
- Hold Command (⌘) on macOS or Ctrl on Windows and Linux for temporary picking. Release the key to exit. Turning off Highlight SPM in split device preview clears the page overlays immediately.

### Device simulation

- Directly opened pages can show the device frame first, then stream the page into the WebView, including URLs with query parameters. Parameterized redirects, form submissions, and pages with unknown navigation sources continue to use top-level navigation.

### Installation and local data

- Plugin installs with `--skill <name>` use the active Skills manager defaults. Use `--agent <id>` to choose an agent or omit `--skill` for interactive selection. Mearl Skill installs and updates also use the manager defaults.
- The Native Host, background plugin service, on-demand Providers, and managed Chrome keep debug logging off by default. Set `MEARL_DEBUG=1` in the service startup environment for diagnostics. Cleanup can reclaim page task records an hour after completion and orphaned Provider logs older than seven days.
- Updating requires no configuration migration. A successful full uninstall with `npx @mearl/setup@3.1.8 uninstall --full` **permanently deletes all of `~/.mearl`**, including local Presets, settings, notes, browser profiles, and caches. Back up any data you want to keep before a full uninstall.
