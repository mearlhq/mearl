### Device simulation

- Directly opened pages can show the device frame first and stream the page into the WebView. This includes URLs with query parameters.
- URLs with query parameters still use top-level navigation after a redirect or form submission, or when Chrome cannot confirm their navigation source. If the WebView’s initial request returns an HTTP redirect, the destination opens at the top level by default.

### Compatibility

- This update requires no configuration or data migration.
