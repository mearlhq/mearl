### Installation and configuration

- Installation automatically accepts defaults without an interactive terminal, so `--yes` is no longer required in that environment. Interactive terminals still show prompts. Non-interactive removal still requires an explicit confirmation flag.
- Fix preset selection with `--skip-skill`: independently managed Skills are preserved while the preset and its declared managed resources are installed normally.
- The Agent service dialog shows installation guidance for the browser's preset. The WeChat app profile installation entry and documentation use `mearlhq/profile-wechat` consistently.

### Browser and command line

- Built-in query presets are loaded when initializing configuration for new users.
- Internal action commands support help output for their parameters and usage.
