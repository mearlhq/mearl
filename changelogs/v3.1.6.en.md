### Extension loading and Skill discovery

- Element picking and SPM highlighting scripts load on demand, reducing work when the extension starts and when regular pages load.
- The Skill discovery page searches skills.sh for Mearl-related Skills by default and fetches documentation from the source repository when you open a Skill. Discovery and previews require access to the relevant online sources.

### CLI guidance

- CLI help and guides clarify control session routing. For subsequent page actions in an existing session, the CLI can restore the browser route from `--session <id>`. Use `--browser` to scope the lookup when the session is ambiguous across hosts.
