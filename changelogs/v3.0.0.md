### 版本重点

Mearl 3.0 将浏览器操作、请求调试和环境模拟连接到浏览器扩展、CLI、TypeScript SDK 与 MCP。Agent 可以复用浏览器登录态，扩展、CDP 和 Provider 共用浏览器操作入口。

### 新增

- 使用 Preset 一起安装 Profile、集成、Skills 和 Provider，并应用默认配置。安装器按组件核验就绪状态，支持保留用户覆盖、补装缺失组件和从已保存的资源恢复中断的升级。
- 本机 setup 在扩展未连接时直接完成本机安装。已连接的扩展可以同步同一份 Preset，稍后连接时可运行 `npx @mearl/setup preset repair` 补同步。
- `npx @mearl/setup extension --extract` 下载并解压扩展，打印可在 Chrome 开发者模式下手动加载的目录。下载和解压无需开启远程调试。
- 在工具栏弹窗或 Agent 侧栏中与 Codex、Qoder 对话，并在对话界面安装缺失的本机 Agent 组件。Codex 对话支持预览引用的 HTML 图表。Qoder 云端配对由可选的 `@mearl/plugin-qoder` 能力单独提供。
- 受支持的固定机型可使用居中的手机壳预览，并在设备旁或下方打开调试面板。页面操作和截图以业务 WebView 为目标；手机壳是否可用取决于所选机型和端模拟配置。
- 可从模拟菜单或通过 `npx @mearl/setup profile install <来源>` 添加 Profile。一个来源可提供多套 Profile，安装会保留当前 Preset。
- `mearl run` 使用 JavaScript 组合浏览器动作与已注册的 Skill 命令，支持顶层 `await`、条件和循环。脚本在独立进程中运行，支持取消、执行期限和输出限制。
- 微信小程序 Skill 支持运行原生小程序和已编译的 `mp-weixin` 产物，复用浏览器页面操作和设备模拟。请求 Mock 通过 `wxa.setup.js` 或运行器测试 API 配置；请求由 Node 转发，不会自动共享浏览器 Cookie 或请求规则。编译器和文件访问要求见[小程序指南](https://github.com/mearlhq/profile-wechat/blob/main/docs/wechat-miniprogram.zh-CN.md)。

### 变更

- 通用使用指南随 CLI 分发。运行 `mearl guide` 阅读核心流程，或用 `mearl guide --list` 查找专题。
- 用 Profile 配置端模拟，用集成和 Skill 扩展业务协议与工具箱。更新使用特定协议 action 的 SDK 或 MCP 脚本时，请核对对应插件的帮助。
- `npx @mearl/setup plugin install <source> --skill <name>` 一次完成 Skill 安装和插件注册。仓库提供设计稿叠加、双语阅读、格式转换、笔记、标签页管理和图片压缩等工具。

### 升级与兼容性

- 核心运行包要求 Node.js 20.18.0 或更高版本，独立 Provider 以各自声明为准。扩展支持 Chrome 120 起，部分功能需要更新的 Chrome 版本。具体要求见[扩展兼容性](https://github.com/mearlhq/mearl/blob/v3.0.0/packages/extension/README.md#浏览器兼容性)。
- 使用扩展时，请配套升级扩展和本机组件，并通过 setup 注册 Native Messaging。Host 名称为 `ai.mearl.skills` 和 `ai.mearl.mcp`。安装后运行 `mearl check --local` 验证连接；使用免扩展 CDP 时运行 `mearl check --cdp`。
- Provider 使用协议版本 3，需配套更新 Provider SDK、重新构建打包的适配器，并在更新 Mearl 宿主后重启 Provider 进程。
- Qoder 云端配对从 macOS Keychain 的 `ai.mearl.qoder.pat` 服务读取 PAT。使用其他服务名保存凭据时需重新配置，也可通过环境变量或环境文件提供 PAT。
