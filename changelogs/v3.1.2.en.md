### Preset installation and permissions

- Open the Preset installation dialog directly from extension settings. With existing site access, you can preview the purpose or capability counts before enabling a Preset. Switching Presets refreshes the preview and required permissions.
- The site permission prompt lets you grant the Agent access to all sites or just the requested site. The Agent integration dialog now describes commonly used capabilities.
- The installer prints the result and next steps as text after installation or update. Scripts that read JSON can call `npx @mearl/setup preset status`. The exit code remains `3` when the Preset is pending.
- Add App Profile no longer includes a built-in WeChat option. You can still install App Profiles manually from supported sources.

### Browser sessions and Providers

- Ending a session closes the tabs it created by default and keeps the user tabs it reused. Use `keepTabIds` to keep specific result tabs or `closeCreatedTabs: false` to keep every tab. Providers without `tab_close` release the session and leave its tabs open.
- On macOS, a Provider that declares a browser's bundle ID can prevent that browser from also appearing in local discovery through its extension. The user's setting controls the Agent service inside the extension.
