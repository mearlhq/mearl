# Mearl 3.0.2

简体中文 | [English](v3.0.2.en.md)

## 📌 版本重点

Preset 支持从本机快照重试安装，也可以通过命令统一卸载。

## ✨ 新增

- `preset uninstall` 移除本机 Preset、已连接扩展中的匹配配置，以及当前 Preset 插件目录中的托管注册。独立能力、Skill 文件、Provider 和浏览器权限会保留。

## ♻️ 变更

- `preset apply` 省略来源时从本机保存的快照重试，替代 `preset repair`。传入 URL 或本地文件可安装或切换 Preset。

## 🐛 修复

- 同仓库的 Skill 缺少分支记录时，安装器从 Preset 指定的分支安装并核验。
- 安装页只根据浏览器需要处理的配置报告浏览器状态，避免因本机安装器配置误报失败。

## 🔄 升级与兼容性

- 运行 `npx @mearl/setup@3.0.2` 安装，或运行 `npx @mearl/setup@3.0.2 update` 更新本机组件。浏览器侧卸载需要配套的 Native Host 和扩展。

[完整变更](https://github.com/mearlhq/mearl/compare/v3.0.1...v3.0.2)
