### Browsers and control sessions

- Use `browser_list` to list browsers and `browser_manage` to launch, attach, detach, release control, or close an instance. Use `session_list` and `session_manage` for task sessions, with `new` and `end` to create and finish them explicitly. Update scripts that use the old commands. The guides shipped with the CLI show the new commands.
- Attach to Chrome and Electron with the CDP Provider. Chrome CDP discovery still works when no extension is connected. Use `browser_manage` with `attach` for an explicit connection.
- The standalone [Firefox Provider](https://github.com/mearlhq/provider-firefox) connects over WebDriver BiDi to Firefox with a local debugging port. It supports page snapshots, clicks, typing, and screenshots. Detaching leaves Firefox and its tabs open.

### Debugging and app emulation

- Record browser pages and export videos. The Toolbox now includes a web terminal.
- Device preview supports SPM highlighting and source tracing, and app emulation controls are easier to access.
