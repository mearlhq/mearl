### 设备外壳

- 修复外部浏览器 Provider 在空白页启用 App 模拟和设备外壳时，等待根 WebView 超时的问题。空白页先准备配置，首次导航进入 HTTP 页面后再等待业务 WebView。
- 保留已有 HTTP 页切换外壳时的刷新行为；业务 WebView 缺失时仍明确报错，不将后续业务操作转到外层页面。
- Ego Provider 内置宿主代码，需要更新到包含本次宿主修复的 Provider 版本才能生效。

### MCP 配置

- 配置向导新增 OpenCode v1/v2、Pi 和 DeepSeek Harness 支持。
- 更新和卸载保留其他服务、设置及 JSONC/YAML 注释；损坏配置会明确报错并保留原文件。安装或重新配置遇到已有远程 Mearl 条目时，同样报错并保留原文件。

### 扩展账户

- 修复授予权限后账户信息未恢复加载的问题。
