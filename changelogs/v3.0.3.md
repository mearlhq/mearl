# Mearl 3.0.3

简体中文 | [English](v3.0.3.en.md)

## 📌 版本重点

官网引导页改为由用户主动启用 Preset，所需授权在扩展内完成。

## ♻️ 变更

- 打开引导页时会检查当前所选 Preset 的状态。点击启用后，扩展打开安装页供用户继续操作。
- 欢迎页直接探测配置的 HTTPS 自定义官网地址。部署者通过 `MEARL_INSTALLATION_CONFIG` 提供安装目录 JSON。
- 更新 Chrome 扩展的中英文产品说明。

## 🐛 修复

- 嵌入式安装按钮省去重复的 Preset 名称，让引导页上的选择和按钮更清楚。

## 🔄 升级与兼容性

- 运行 `npx @mearl/setup@3.0.3` 安装，或运行 `npx @mearl/setup@3.0.3 update` 更新本机组件。使用配套的引导页和扩展。

[完整变更](https://github.com/mearlhq/mearl/compare/v3.0.2...v3.0.3)
