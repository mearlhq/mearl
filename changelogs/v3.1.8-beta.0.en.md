### SPM inspection

- Use the SPM picker in the panel to select a highlighted item and view its full tracking point, type, tracking configuration, and DOM details.
- Click the picker once to select a single item, or double-click for continuous picking. Select the same spot repeatedly to cycle through overlapping SPM highlights.

### Full uninstall and local data

- A successful `npx @mearl/setup@3.1.8-beta.0 uninstall --full` permanently deletes all of `~/.mearl`, including local Presets, settings, notes, browser profiles, and caches. Back up any data you need before a full uninstall.
- Debug logging is opt-in for Native Host, the background plugin service, on-demand Providers, and managed Chrome. Set `MEARL_DEBUG=1` in the environment that starts the service when troubleshooting.
- Page event handlers use their input and unused return values only during execution. Regular cleanup can remove finished page task records after one hour. Provider discovery reclaims orphaned logs older than seven days.
