### Added

- Discover and invoke WebMCP tools declared by pages, with a toolbox panel for bb-browser site adapters.
- Manage capability presets from extension settings, with improvements to tool installation and permission settings.
- A native page host for the independent Ego Provider, including page operations, device shells, root WebViews, and installed App protocol and authorization services.
- Providers can declare macOS browser Bundle IDs to default that profile's extension Agent access off. Users can override the preference locally; it does not sync across browsers or automatically revert when a Provider goes offline or is removed.
- `pnpm dev:link` builds and links local CLI packages for source development.

### Fixes and compatibility

- Agent access remains blocked until coordination completes. File uploads, batched page actions, and cookie copying also respect the switch. The management connection remains available for installation and settings.
- Host requests abort when control is revoked, preventing stale authorization from continuing after control returns. Policy updates use change events without additional polling.
- Ego uses the independent `provider-ego`; the `mearl-ego` Skill is removed and bilingual website guides are updated. Update both the extension and Native Host, then register the Provider again to enable coordination.
