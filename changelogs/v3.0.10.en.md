### Device shell

- Fix root WebView timeouts when external browser Providers enable App simulation and a device shell on a blank page. Prepare the configuration first, then wait for the business WebView after the first navigation to an HTTP document.
- Preserve reload behavior when switching the shell on existing HTTP pages. Missing business WebViews still produce explicit errors instead of redirecting later operations to the outer page.
- Ego Provider bundles the host implementation and must be updated to a version containing this fix.

### MCP configuration

- Add configuration support for OpenCode v1/v2, Pi and DeepSeek Harness.
- Updates and removal preserve other services, settings and JSONC/YAML comments. Invalid configurations produce explicit errors without overwriting the files. Installation or reconfiguration also rejects existing remote Mearl entries without modifying them.

### Extension accounts

- Restore account loading after permissions are granted.
