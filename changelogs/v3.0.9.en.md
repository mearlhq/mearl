### Installation guidance

- On first installation, probe the welcome page configured at build time and open it when reachable. Failed or timed-out probes fall back to the public welcome page. The probe no longer depends on Manifest host permissions for the target website.
- Local builds support welcome-page configuration through `.env.local`; release builds read the corresponding GitHub repository variable.

### Updates and releases

- The extension, CLI checks, and stable setup read update configuration from GitHub Pages. Successful publication refreshes the website configuration independently of store review submission.
- Beta setup downloads the extension ZIP matching its own version directly. Explicit update configuration sources remain supported.
- Releases attach only the extension ZIP and license, without `config.json` or `toolbox.json`. Clients relying on the old Release configuration URL need to upgrade.
- Remove persistent extension host permissions for `github.com` and `release-assets.githubusercontent.com`.
