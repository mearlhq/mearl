# Mearl 3.0.4

[简体中文](v3.0.4.md) | English

## 📌 Highlights

Custom and product websites use the same Preset installation flow. The extension groups required site permissions in one prompt.

## 🐛 Fixes

- Custom and product installation pages load Presets from a same-origin catalog. Users confirm installation in the extension.
- Setup reuses healthy managed plugins during installation and updates, avoiding repeated installs. Explicit status queries still produce JSON.
- Permission prompts group the sites required by a capability so users can review the domains together.

## 🔄 Upgrading and compatibility

- Run `npx @mearl/setup@3.0.4` to install, or `npx @mearl/setup@3.0.4 update` to update local components. Use matching versions of the installation page and extension.
